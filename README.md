## 👕 About the Project

**Kouman** is a modern web-based clothing merch application.  
It allows users to browse merch items, manage a shopping cart, and enjoy interactive animations — all with a fully responsive design.

Built with **Next.js**, **React**, **TypeScript**, **Tailwind CSS**, and **Zustand**, this project demonstrates advanced front-end skills in building a real-world e-commerce experience.

---

## 🛍️ Features

<ul>
  <li>🏠 <b>Home Page</b> — Stylish landing page with an image slider</li>
  <li>🧭 <b>Navigation Bar</b> — Smooth navigation across pages</li>
  <li>🛒 <b>Shopping Cart</b> — Add, remove, and manage items (Zustand state management)</li>
  <li>💻 <b>Responsive Design</b> — Fully functional on mobile, tablet, and desktop</li>
  <li>🎨 <b>Modern UI</b> — Hover effects, gradients, shadows, and smooth animations</li>
</ul>

| Technology | Purpose |

| 🎨 **Tailwind CSS** | Modern, responsive design |
| 🪄 **Zustand** | Lightweight global state management |

---

## 💡 Description

This project replicates a real-world clothing e-commerce platform with modern UI/UX principles.  
Users can browse merch, add items to the cart, and interact with a fully reactive interface.  

Zustand ensures smooth global state updates, providing a seamless shopping experience.  

Perfect for practicing **React**, **Next.js**, **TypeScript**, **Tailwind CSS**, and **Zustand** in a real-world scenario.
